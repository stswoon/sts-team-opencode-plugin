# Субагенты

Плагин регистрирует четыре субагента через `ctx.agent.transform` (`mode: subagent`):

| Субагент    | Описание           | Пишет код                                        | Пишет спеку/план              | Когда                                                                            |
|-------------|--------------------|--------------------------------------------------|-------------------------------|----------------------------------------------------------------------------------|
| **analyst** | Системный аналитик | нет                                              | да (`docs/spec`, `docs/plan`) | `sts-team-plan`                                                                  |
| **dev**     | Разработчик        | да (код проекта + тесты)                         | только уточнение цифр         | `sts-team-impl`, после замечаний; регрессионный тест на каждый исправимый дефект |
| **qa**      | Независимый QA     | production-код нет; тесты — если дыра в проверке | нет                           | после Dev; независимая матрица приёмки в `bug-report-Sxx.md`                     |
| **lead**    | Lead-ревьюер       | нет                                              | нет (`review-notes-Sxx.md`)   | после доказательного `QA_PASS`, сверка кода и тестов со спекой                   |

Статус стори (`сделано` / `не сделано`) меняет **оркестратор** `sts-team-impl` после `LEAD_PASS`, не эти агенты.

`sts-team-plan` любые допущения и нестыковки выносит вопросами пользователю. `sts-team-impl` допущения закрывает сам (решения
`D…` в `.cursor/artifacts/decisions.md`), а нестыковки и расхождения со спекой выносит пользователю.

Субагент не видит историю родительского чата: в промпт `subagent` передавай текст стори, решения `D…` этой стори и пути
к отчётам предыдущего шага с выжимкой активных блокеров — файлы субагент читает сам, полные тексты не копируй.

Без плагина роли можно описать в секции `agents` конфига или положить файлами в `.opencode/agents/`. Формат V2:
frontmatter `description` / `mode`, тело — системный промпт; ID агента берётся из имени файла (`analyst.md` →
`analyst`), поле `name` не нужно. В этом случае замени в `analyst.md` плейсхолдер `{{PACKAGE_DIR}}` на путь к пакету.

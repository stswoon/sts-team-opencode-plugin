# Шаблон метаданных работы в tasks.md

Вставляй после заголовка фазы, до `**Цель**` / `**Goal**`.

````markdown
## Phase 3: История 1 — <название> (Приоритет: P1)

**Статус:** OPEN
**Дорожка:** api, web
**Параллель:** US2, US3 — по файлам; не параллелить: —
**Зависит от:** FOUNDATION
**Разблокирует:** US4
**Папки (только эти):**
```
apps/api/src/modules/users
apps/web/src/pages/users
```
**Ресурсы:** ui
**Приёмка:** US1 acceptance 1–3; FR-001..FR-004
**Не делать:** <что сознательно не делать в этой работе>

**Цель**: ...
````

Для `FOUNDATION` статус ставится в Phase 1 и Phase 2, и это **одна** работа: `**Зависит от:**` и `**Разблокирует:**` у
обеих фаз одинаковые, не ссылайся на Phase 1 как на отдельную работу. Для `POLISH` и `CONV` — в их фазах.

Блок эксклюзивных путей — в начале `tasks.md`, после блока «Пути»:

````markdown
**Эксклюзивные пути:**
```
packages/contracts/openapi.json
apps/api/src/database/migrations/
apps/web/src/shared/lib/i18n/messages/
pnpm-lock.yaml
package.json
```
````

Блок фронта — после фаз, перед «Зависимости и порядок выполнения»:

````markdown
## Фронт поставки ({{N_SLOTS}} слота)

| Волна | Готовые работы | Ширина | Узкое место |
|-------|----------------|--------|-------------|
| 1 | FOUNDATION | 1 | блокирует все US |
| 2 | US1, US2 | 2 | общий `packages/contracts/openapi.json` |

Максимальная ширина: 2. Узкое место: US2 — общий контракт.
Попытки расширить: снята нежёсткая зависимость US3 от US1; US2 сериализована по контракту.
````
